## 4. Осознанные решения, которые могут выглядеть как недоделки

| Решение | Почему так |
|---|---|
| Свежая проверка администратора — клик подтверждения, а не повторный ввод пароля | Повторная аутентификация требует потока, которого у нас нет. Баннер говорит ровно то, что происходит, а не изображает большее |
| Приглашение в команду показывает ссылку вместо письма | Почтовый провайдер не подключён. Экран прямо просит передать ссылку самостоятельно |
| Экспорт данных выдаёт подписанный токен, но не файл | Генерация и доставка файла не реализованы; токен и срок — реальные |
| Хард-делит нигде не предлагается | Архив и устаревание сохраняют историю. Отказ объясняется, а не выглядит ошибкой |
| Скачок во времени существует только в DEMO_MODE | Это инструмент показа, а не функция продукта. В PRODUCTION_MODE его нет |
| `verified_fact` не может быть создан | Пока нет подключённого источника, любое такое значение было бы ложью. База это запрещает |

## 6. Как этот список поддерживать

Он не должен стать историческим документом. Правило: **строка отсюда удаляется только вместе
с проверкой, которая доказывает, что ограничение снято.** Если проверки нет — ограничение
остаётся в списке, каким бы очевидным ни казалось, что оно исправлено.
