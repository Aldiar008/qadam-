## 3. Что нужно сделать **нам** до первого боевого запуска

Это не блокеры внешней стороны — это работа, которую откладывать нельзя, но которая
осмысленна только после появления цели развёртывания.

1. **Общий стор для rate limit и защиты от повтора.** Сейчас `Map` в памяти процесса.
   За несколькими инстансами лимит станет «N × лимит». Нужен Redis или таблица с TTL.
2. **Перенос секретов из `.env` в секреты платформы.** Локально всё в `.env.local`; на
   хостинге — переменные окружения окружения, разные для staging и production.
3. **Пул соединений.** Приложение должно ходить через pooler (`:6543`, transaction mode),
   а не в `:5432`. Миграции и бенчмарк — наоборот, напрямую.
4. **Таймауты на роль приложения:**
   ```sql
   alter role authenticated set statement_timeout = '8s';
   alter role authenticated set idle_in_transaction_session_timeout = '15s';
   ```
5. **Тренировка восстановления из бэкапа.** Процедура написана, но **ни разу не выполнялась**.
   До первого боевого тенанта её нужно пройти целиком на staging.
6. **Перемер SLO.** Текущие цифры — с одного локального процесса и не переносятся.
